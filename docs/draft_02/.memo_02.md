## コンポーネントの推奨設計

利用者側にどういう設計を求めるのかを言語化していないため、行き詰まった。

まずは、「1ページ1Step」の設計を前提にした。

Stepというのは、「ユーザー情報入力」「入力確認」のような、1画面単位の操作を表す。
ということは、1ファイルの中に`defineStep`が乱立するような設計は、推奨とはならない。

そうなると、「1ページ1Step」あるいは「1モーダル1Step」という考えを前提としておきたい。

```ts
// イメージ
const AskName = defineStep("name", ({ context, complete }) => {
    return (
        <input
            ...
            onsubmit={...}
        />
    )
});
```

今まで`Input`と`Output`の両方の型を定義していました。
しかし、そもそもOutputが次のInputに入るような連鎖なので、具体的な型は1つにした方が良いです。

```ts
export type StepPayload = Record<string, unknown>;
```

---

関数で画面を作って操作する考えはReactに合わなかったため、Reactコンポーネントを素直に使う方針にしました。

Component型を使うことで、Reactのライフサイクルと一致させやすいという考えです。

> StepViewComponentは、具体的に実装を書くためのコンポーネントです。
> 例えば、「ユーザーから名前を入力してもらうStep」なら、具体的に名前の入力フォームを実装したりするところです。

```ts
export type Complete<TOutput extends StepPayload> = (
  output: TOutput
) => void;

export type StepViewProps<
  TContext extends StepPayload,
  TOutput extends StepPayload
> = {
  context: TContext;
  complete: Complete<TOutput>;
}

export type StepViewComponent<
  TContext extends StepPayload,
  TOutput extends StepPayload
> = ComponentType<StepViewProps<TContext, TOutput>>;
```

> DefineStepComponentは、StepViewComponentの外側にあるコンポーネントです。
> `<DefineStep name="askName" component={AskNameStepView} />`のように使います。

```ts
export type DefineStepProps<
  TContext extends StepPayload,
  TOutput extends StepPayload
> = {
  name: string;
  component: StepViewComponent<TContext, TOutput>;
}

export type DefineStepComponent = <
  TContext extends StepPayload,
  TOutput extends StepPayload
>(
  props: DefineStepProps<TContext, TOutput>
) => ReactNode;
```

> FlowComponentは、操作の流れを定義する場所です。

```ts
export type FlowProps<TContext extends StepPayload> = {
  initialContext: TContext;
  children?: ReactNode;
}

export type FlowComponent = <TContext extends StepPayload>(
  props: FlowProps<TContext>
) => ReactNode;
```

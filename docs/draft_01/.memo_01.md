最終的に以下を実現することを考えます。

```tsx
const NameStep = defineStep<{ defaultName: string }, { name: string }>(
  'name',
  ({ context, next }) => {
    const [name, setName] = React.useState(context.defaultName);
    return (
      <div>
        <h2>Step 1: 名前入力</h2>
        <input value={name} onChange={(e) => setName(e.target.value)} />
        <button onClick={() => next({ name })}>次へ</button>
      </div>
    );
  }
);
```

これをいきなり実装するのは難しいです。
そこで、先に振る舞いを定義してガードレールを敷きます。

---

まず、入力と出力については、`defaultName`や`AuthState`のようなどんな名前でも受け入れる必要があります。
そのため、型は`Record`を使います。

```ts
type Input = Record<string, unknown>;
type Output = Record<string, unknown>;
```

---

`StepResult`型を作ります。

1ステップが終わるごとに出力とコンポーネントをセットで返します。

```ts
export type StepResult<TOutput> = {
  output: TOutput,
  component: React.ReactNode
};
```

---

`Step`型を作ります。

Stepは「contextを渡してから出力するまで」という意図で、以下のようにします。
UI上で`next()`が呼ばれるのを待つ必要があるので、Promiseにしておきます。

```ts
type Input = Record<string, unknown>;
type Output = Record<string, unknown>;

export type Step<TInput, TOutput> = (
  context?: TInput
) => Promise<StepResult>;
```

---

`StepComponent`型を作ります。

```ts
import type { FunctionComponent } from "react";

export type StepComponent<TInput, TOutput> = FunctionComponent<{
  context?: TInput,
  next: (output: TOutput) => void
}>;
```

StepCompontは以下のようになります。

```tsx
({ context, next }) => {
  const [name, setName] = React.useState(context.defaultName);

  return (
    <div>
      <h2>Step 1: 名前入力</h2>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <button onClick={() => next({ name })}>次へ</button>
    </div>
  );
}
```

---

最後に、defineStepでまとめます。

```ts
export interface ReactFlow {
  defineStep: <
    TInput extends Input = Input,
    TOutput extends Output = Output
  >(
    name: string,
    component: StepComponent<TInput, TOutput>
  ) => Step<TInput, TOutput>
}
```

## 目指すコード

APIを使用する側が目指すコードについておさらいします。

### 1

`defaultName`というcontextを要求して、`name`を返すと約束します。

```tsx
const NameStep = defineStep<{ defaultName: string }, { name: string }>();
```

### 2

`context`には`defaultName`が入ります。
`next()`は`name`を要求し、呼ばれると次の画面に遷移します。

```tsx
const NameStep = defineStep<{ defaultName: string }, { name: string }>(
  'name',
  ({ context, next }) => {}
);
```

### 3

`next({ name })`を呼ぶと、`{ name }`が次の画面のcontextとして働きます。

```tsx
const NameStep = defineStep<{ defaultName: string }, { name: string }>(
  'name',
  ({ context, next }) => {
    ////////////////////////////////////////////////////////////////////////
    const [name, setName] = React.useState(context.defaultName);
    return (
      <div>
        <h2>Step 1: 名前入力</h2>
        <input value={name} onChange={(e) => setName(e.target.value)} />
        <button onClick={() => next({ name })}>次へ</button>
      </div>
    );
    ////////////////////////////////////////////////////////////////////////
  }
);
```

### ユーザー登録の例

```tsx
// Step 1: メール入力
const EmailStep = defineStep<undefined, { email: string }>(
  'email',
  ({ next }) => {
    const [email, setEmail] = React.useState('');

    const handleNext = () => {
      if (!email.includes('@')) return alert('形式が不正です');
      next({ email });  // email を次の画面に伝えて遷移
    };

    return (
      <div>
        <h2>Step 1: メール入力</h2>
        <input value={email} onChange={(e) => setEmail(e.target.value)} />
        <button onClick={handleNext}>次へ</button>
      </div>
    );
  }
);

// Step 2: 登録処理
const ConfirmStep = defineStep<{ email: string }, { success: boolean }>(
  'confirm',
  ({ context, next }) => {
    const handleConfirm = async () => {
      const { success } = await api.registerUser(context.email);
      next({ success });  // 登録時の結果を次の画面に伝えて遷移
    };

    return (
      <div>
        <h2>Step 2: 確認</h2>
        <p>登録メール: {context.email}</p>
        <button onClick={handleConfirm}>登録する</button>
      </div>
    );
  }
);

// Step 3: 結果表示
const ResultStep = defineStep<{ success: boolean }>(
  'result',
  ({ context, next }) => {
    return (
      <div>
        <h2>Step 3: 登録結果</h2>
        {context.success ? (
          <p>ユーザー登録が完了しました！</p>
        ) : (
          <p>登録に失敗しました。時間をおいて再度お試しください。</p>
        )}

        {/* 後続に処理がない場合は、next() を呼ぶか放置する */}
        <button onClick={() => next()}>閉じる</button>
      </div>
    );
  }
);
```

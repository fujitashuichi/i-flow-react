実装に入っていきます。

最初に作った型を確認しておきます。

```ts

type Input = Record<string, unknown>;
type Output = Record<string, unknown>;

export type StepResult<TOutput> = {
  output: TOutput,
  component: React.ReactNode
};

export type Step<TInput, TOutput> = (
  context?: TInput
) => Promise<StepResult<TOutput>>;

export type StepComponent<TInput, TOutput> = FunctionComponent<{
  context?: TInput,
  next: (output: TOutput) => void
}>;


export interface ReactFlow {
  defineStep: <
    TInput extends Input,
    TOutput extends Output
  >(
    name: string,
    component: StepComponent<TInput, TOutput>
  ) => Step<TInput, TOutput>
}
```

---

まず、`runStep`という関数を考えます。

```ts
export const runStep = <TInput, TOutput>(
  stepComponent: StepComponent<TInput, TOutput>,
  context?: TInput
): StepResult<TOutput> => {
  return ...
}
```

まず、`stepComponent`というのはUIで渡されるコンポーネントです。
TInputは`context`に、TOutputは`next`に入れる引数に対応します。

```tsx
({ context, next }) => {
  const [name, setName] = React.useState(context.defaultName);
  return (
    <div>
      <h2>Step 1: 名前入力</h2>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <button onClick={() => next({ name })}>次へ</button>
    </div>
  );
}
```

重要なのは「この時点ではコンポーネントは未完成」ということです。

TSX側からすると「`context`や`next`の中身は降ってくる」という状況です。
具体的な実装は`runStep`側で注入する必要があります。

```ts
import type { StepComponent, StepResult } from "./interface/ReactFlow.types";

export const runStep = async <TInput, TOutput>(
  stepComponent: StepComponent<TInput, TOutput>,
  context?: TInput
): Promise<StepResult<TOutput>> => {
  let component: React.ReactNode;

  const output = await new Promise<TOutput>(async (resolve) => {
    component = await stepComponent({
      context,
      next: (output: TOutput) => resolve(output)
    });
  });

  return {
    output,
    component
  }
}
```

ただ、これだと`Promise`の中に`async`があってよくありません。
そのため、まずは`stepComponent`が非同期だった際に待つ必要があります。

```ts
export const runStep = async <TInput, TOutput>(
  stepComponent: StepComponent<TInput, TOutput>,
  context?: TInput
): Promise<StepResult<TOutput>> => {
  let resolveOutput: (output: TOutput) => void;

  const outputPromise = new Promise<TOutput>((resolve) => {
    resolveOutput = resolve
  });

  // componentが作られるのを待つ
  // outputの解決を任せる
  const component = await stepComponent({
    context,
    next: (output: TOutput) => resolveOutput(output)
  });

  // nextが呼ばれるまで待機することができる
  const output = await outputPromise;

  return {
    output,
    component
  }
}
```
